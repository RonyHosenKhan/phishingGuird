Lab Viva Q&A (Quick Reference for Sir)

Q1: Why use an Autoencoder instead of only supervised classification?
Supervised models (like Random Forest) only recognize known phishing attack patterns present in training data. Attackers frequently invent Zero-Day polymorphic URLs or novel obfuscations. The Autoencoder is trained only on legitimate communications; when an unseen threat arrives, its reconstruction error (MSE) spikes above threshold ε, flagging zero-day threats without needing prior labels!
Q2: How does on-device inference protect user privacy?
Traditional scanners send full message bodies, contacts, and bank OTPs to cloud servers. PhishGuard AI runs quantized INT8 TFLite / ONNX models 100% locally on device using mobile ARM NEON/NPU. Zero raw text leaves the phone!
Q3: How does NotificationListenerService intercept messages?
Android's NotificationListenerService receives StatusBarNotification broadcasts from system apps (SMS, WhatsApp, Gmail). It extracts EXTRA_TEXT and EXTRA_TITLE bundles for inspection before the user clicks malicious links.

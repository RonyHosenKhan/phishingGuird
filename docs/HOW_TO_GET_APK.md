## 🚀 আপনার Android APK ফাইলটি তৈরি করার ২টি সহজ উপায়

আমরা আপনার প্রজেক্টের `android_native/` ফোল্ডারে সম্পূর্ণ নেটিভ অ্যান্ড্রয়েড কোডবেজ তৈরি করে রেখেছি। নিচের যেকোনো ১টি উপায়ে আপনি সরাসরি `.apk` ফাইল পেয়ে যাবেন:

---

### উপায় ১: Android Studio দিয়ে (সবচেয়ে সহজ ও ল্যাব প্রজেক্টের জন্য সেরা)

যদি আপনার বা আপনার বন্ধুর কম্পিউটারে **Android Studio** ইনস্টল করা থাকে:
1. **Android Studio** ওপেন করুন।
2. **File -> Open** এ ক্লিক করে আপনার প্রজেক্ট ফোল্ডারটি সিলেক্ট করুন:  
   👉 `C:\Users\khanr\.gemini\antigravity-ide\scratch\phishguard-ai\android_native`
3. প্রোজেক্ট ওপেন হলে Android Studio স্বয়ংক্রিয়ভাবে গ্রেডল সিঙ্ক (Gradle Sync) করে নিবে।
4. উপরের মেনু বার থেকে ক্লিক করুন:  
   👉 **`Build` -> `Build Bundle(s) / APK(s)` -> `Build APK(s)`**
5. ১-২ মিনিটের মধ্যে নিচে একটি পপআপ আসবে:  
   `"APK(s) generated successfully: locate"`
6. **`locate`** এ ক্লিক করলেই আপনার কাঙ্ক্ষিত **`app-debug.apk`** ফাইলটি পেয়ে যাবেন!

---

### উপায় ২: GitHub Actions ক্লাউড বিল্ডার দিয়ে (কম্পিউটারে কোনো সফটওয়্যার ইনস্টল ছাড়াই!)

আপনার সুবিধার জন্য আমরা `.github/workflows/build_apk.yml` ফাইল তৈরি করে দিয়েছি:
1. আপনার GitHub একাউন্টে একটি নতুন রিপোজিটরি তৈরি করুন (যেমন: `PhishGuard-AI`)।
2. আপনার এই `phishguard-ai` ফোল্ডারটি GitHub-এ আপলোড (বা Git Push) করুন।
3. GitHub-এর **Actions** ট্যাবে যান -> **Build Android APK** সিলেক্ট করে **Run workflow** বাটনে ক্লিক করুন।
4. ২ মিনিটের মধ্যে GitHub স্বয়ংক্রিয়ভাবে ক্লাউড সার্ভারে APK কম্পাইল করে দিবে।
5. রান শেষে **Artifacts** সেকশনে ক্লিক করলেই সরাসরি **`PhishGuardAI-Debug-APK.zip`** ডাউনলোড হয়ে যাবে, যার ভেতরে রেডি `.apk` ফাইল থাকবে!

## 📲 ফোনে APK ইনস্টল ও লাইভ ফিশিং অ্যালার্ট চালু করার নিয়ম

আপনার তৈরি করা `app-debug.apk` ফাইলটি ব্লুটুথ, ইউএসবি কেবল বা গুগল ড্রাইভের মাধ্যমে আপনার অ্যান্ড্রয়েড ফোনে নিন। এরপর নিচের ধাপগুলো অনুসরণ করুন:

### ধাপ ১: APK ইনস্টল করুন
- ফোনে `app-debug.apk` ফাইলে ট্যাপ করুন।
- যদি *"Install unknown apps"* ওয়ার্নিং আসে, তবে **Settings -> Allow from this source** অন করে ইনস্টল সম্পন্ন করুন।

### ধাপ ২: Notification Listener পারমিশন দিন (বাধ্যতামূলক)
অ্যান্ড্রয়েডে নোটিফিকেশন ইন্টারসেপ্ট করার জন্য এটি একমাত্র অফিশিয়াল উপায়:
1. অ্যাপটি ওপেন করে প্রথম বাটনটিতে ক্লিক করুন: **`1. Grant Notification Listener Access`**।
2. ফোনের সেটিংসের তালিকা থেকে **PhishGuard AI** খুঁজে বের করে টগলটি **ON** করে দিন এবং **Allow** চাপুন।

### ধাপ ৩: Accessibility সার্ভিস অন করুন (স্ক্রিনের লিংক স্ক্যানের জন্য)
1. অ্যাপের দ্বিতীয় বাটনে ক্লিক করুন: **`2. Grant Accessibility Screen Scanner`**।
2. **Downloaded Apps** বা **Accessibility** লিস্ট থেকে **PhishGuard Screen Inspector** অন করে দিন।

### ধাপ ৪: লাইভ টেস্ট করুন!
- অ্যাপের ৩য় বাটনে ক্লিক করুন: **`3. Test Threat Detection Alert`**। সাথে সাথে আপনার ফোনের স্ক্রিনে ফিশিং অ্যালার্ট নোটিফিকেশন পপ-আপ হবে!
- এখন আপনার বন্ধুকে বলুন আপনাকে একটি ভুয়া লিংকসহ SMS পাঠাতে (যেমন: `bKash: Your account suspended. PIN verify: http://bkash-verify-pin.tk`)। 
- সাথে সাথে PhishGuard AI ব্যাকগ্রাউন্ডে মেসেজটি ইন্টারসেপ্ট করবে এবং অ্যালার্ট সাউন্ডসহ হাই-প্রায়োরিটি সিস্টেম ওয়ার্নিং নোটিফিকেশন দেখাবে!
